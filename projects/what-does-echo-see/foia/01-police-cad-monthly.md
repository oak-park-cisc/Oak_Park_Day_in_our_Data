Dear FOIA Officer,

Under the Illinois Freedom of Information Act (5 ILCS 140), I request the following records in electronic form, preferably CSV or Excel. I'm requesting aggregate counts only. **I'm not asking for addresses, names, incident numbers, narratives or any individual call records.**

**1. Monthly calls for service by call type and disposition, January 2022 to the most recent complete month.**
For each month, call type and disposition, the number of calls for service handled by the Oak Park Police Department. If disposition can't be included, counts by month and call type alone are still very useful.
- I'm most interested in the call types listed in the Village's June 2026 Alternative Response Phase 2 presentation (MOT 26-176): Crisis Intervention, Involuntary Committal, Mental Health, Psychiatric Abnormal Suicide, Suicide, Domestic Disturbance, Harassment, Child Abuse Neglect, Remove Unwanted, Welfare Check, Vagrant, Panhandler, Unconscious Fainting, Person Down, Missing Adult, Missing Juvenile/Runaway, Confused Person, Child Custody Dispute and Truancy. All call types would be better still, so these can be compared with call types that ECHO doesn't handle.
- If the CAD or records system has a disposition or referral code for referral to the Village's E.C.H.O. program, please include counts by that code.

**2. Time on scene.** For the same months and call types, the total minutes officers spent on scene and the number of calls those minutes cover. Totals rather than averages let periods be combined correctly. If only averages are available, averages with call counts are fine.

**3. Repeat locations, as counts only.** For each month from January 2022, the number of distinct locations with 3 or more calls for service of the call types in item 1 within the preceding 90 days. **Please provide only the count of locations, not the locations themselves.**

To protect privacy, please replace any count from 1 to 4 with "suppressed" before release.

If any item would require creating a new record, please tell me what existing reports or standard queries the Department has (for example, monthly CAD summary reports by call type), and I'll narrow the request to those. If the request is unduly burdensome as written, I'm glad to narrow it, for example to January 2023 onward or to the call types in item 1.

This request is for a civic data project reviewing the E.C.H.O. program for the Oak Park Board of Health. It isn't for commercial use. If fees are expected to exceed $25, please contact me first.
