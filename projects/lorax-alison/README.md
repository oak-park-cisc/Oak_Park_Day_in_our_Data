# Our community project

Start with a question your team cares about. Explore the files, edit them yourself, or ask an agent for help.

The CSV in this starter is fictional sample data to exercise the workspace. It is not Oak Park research data. Replace it with your event's public datasets before drawing conclusions.

## First steps

1. Choose a question and record it here.
2. Inspect data/sample.csv.
3. Make a small chart, query, or explanation.
4. Share your changes with your team.

## Oak Park urban forest map

Run `npm install`, then `npm run dev`. Rebuild the data in `public/data` with `python3 scripts/prepare_data.py`; sources and methods are in `public/data/SOURCES.md`.
