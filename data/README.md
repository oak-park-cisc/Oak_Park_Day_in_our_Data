# Data

- [Oak Park Civic Data Catalog](open-data-catalog.md) — the attendee-friendly, categorized catalog of Village, Cook County, regional, and federal data sources.
- [Project Ideas](../project-ideas.md) — starter challenges that use many of the cataloged resources.

The catalog consolidates alternate portal views and download formats for the same underlying resource. It is maintained as Markdown so it renders directly on GitHub and produces readable change history.
